# Banco de dados do ProntoJá

- `migrations/` — rode no **SQL Editor** do Supabase, **em ordem** (001, 002, ...). Cada arquivo pode ser rodado mais de uma vez.
- `seed_exemplo.sql` — contas e dados de teste. **Apague as contas de teste antes do lançamento.**
- `testes/` — testes automáticos usados no desenvolvimento (Postgres local). **Não rode no Supabase.**
